# Coverage Manifest

The [testing inventory](../specs/testing.md) defines each behavior ID. Each row below prescribes the cases to exercise at its owning boundary. Apply the inventory’s named contexts, validation rules and outcomes to each case. Evidence links identify the test declaration or its collected parameterized case. Live eval IDs provide additional provider qualification.

**Covered** means deterministic assertions demonstrate the required cases. **Partial** means some cases have evidence and the remaining cases are named. **Uncovered** means none of the required cases has verifying evidence.
